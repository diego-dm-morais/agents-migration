# Idiom map

Read this when you fill the Construct mapping table of `plan.md` (templates.md), or when you choose the target idiom for a source construct that a spec touches.

Idiom names are generic labels. The syntax and semantics of each one are in the language skill named by the column header; load it before you write target code (migration-conduct section 10). The `Parity risk` column names the trap to pin with the test of the matching category in SKILL.md section 1.

Skills present under `.claude/skills/` (Glob, this run): nodejs, javascript, dotnet, golang, java, rust, flutter, python, typescript. Checked in this run against section 6 of the nodejs skill: the nodejs cells for exact decimal, binary floating point, fixed-width integer, rounding to nearest, fixed-decimal text, text string, byte sequence and charset decoding. Not checked in this run: the nodejs cells for integer division and remainder, case folding, regular expression, date-only value and epoch timestamp, and every cell of the other columns. Verify them against each language skill before the plan relies on them.
